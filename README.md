# Multi-Utility Toolkit

A Python-based command-line toolkit that demonstrates modular programming, built-in library features, dynamic inspection, and custom package implementation.

---

## Features

- **Datetime & Time Operations:**
  - View current date and time
  - Calculate difference between two dates
  - Format dates with custom patterns
  - Built-in Stopwatch and Countdown Timer

- **Mathematical Computations:**
  - Factorial calculations
  - Compound Interest solver
  - Trigonometric values ($sin$, $cos$, $tan$)
  - Area calculations for geometric shapes

- **Random Data Generation:**
  - Random number generator
  - Random integer list generator
  - Secure random password generator
  - 6-digit OTP generator

- **UUID Generation:**
  - Unique identifier generation using `uuid4`

- **Custom File Operations Package:**
  - Create new text files
  - Write data to files
  - Read file contents
  - Append data to existing files

- **Dynamic Module Exploration:**
  - Inspect attributes of any standard or installed Python module dynamically using `dir()`.
